 # Implementacao

## Objetivo

Implementar uma demanda aprovada preservando contratos e qualidade.

## Instrucoes

Leia somente contexto liberado. Trabalhe em mudanca pequena. Use JDK 21 (sem Lombok) no backend, Angular 19 no frontend e MySQL quando houver persistencia. Escreva ou atualize testes. Registre `author_agent_id`, arquivos alterados, comandos e limitacoes.

O CRUD deve continuar funcionando quando uma capacidade de IA estiver indisponivel. Nao adicione dependencia, segredo ou chamada de modelo sem justificativa.

## Saida

Codigo, testes, documentacao, resultado das validacoes e pedido de Code Review independente.
