 # Levantamento de Requisitos

## Objetivo

Transformar uma necessidade em requisitos verificaveis para o CRUD IA First.

## Instrucoes

Identifique atores, caso de uso, entradas, saidas, regras de negocio, riscos, criterios de aceite e evidencia esperada. Pergunte quando houver ambiguidade. Nao escolha implementacao sem necessidade.

## Saida obrigatoria

```yaml
requirement_id: REQ-001
statement: descricao verificavel
priority: must
acceptance_criteria:
	- criterio observavel
evidence: nome-do-teste-ou-relatorio
```

Inclua limites, dados permitidos e se IA e realmente necessaria.
